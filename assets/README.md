# Fonts

Modern DOS 8x16 by Jayvee Enaguas, CP437 bitmaps distributed by Susam Pal's
PC Face project. Bitmap distribution used under its MIT license, reproduced
in LICENSE-PCFACE.txt. Original font is CC0. No REXPaint asset is used.

Source: https://github.com/susam/pcface/tree/main/out/moderndos-8x16
Vendored source: moderndos-source.js. Binary: 256 glyphs × 16 row bytes,
most significant bit at the left. SHA-256:

`78887614b4b94bfa350be2f18aa64b96df52044bbd802cf60e812a9080be1478`

Document cells use the original 8 × 16 mask doubled horizontally to 16 × 16;
UI characters use 8 × 16 metrics. The atlas and the export share these bits.

## Extended glyphs (Ditto 0.2)

The original binary and its checksum are unchanged. Additional 16 × 16 masks are
generated by Ditto from geometric definitions (fractions, quadrants, sextants,
textures, braille and a few supplemental strokes). They do not depend on a system
font. The GPU atlas and PNG export share these exact masks.

## SF Mono (Ditto 0.3)

SF Mono is loaded at runtime from the local macOS font installation. No Apple font
file is bundled, copied into projects, or included in distribution archives.
Fontdue rasterizes the outlines into an in-memory antialiased atlas shared by
the UI and canvas. PNG export uses the same coverage masks. Missing glyphs fall
back to the geometric catalogue above. Linux resolves an installed monospace font
when SF Mono is unavailable; DITTO_FONT_PATH can select a local font file.
